<SheetGrid>
  <SheetCard title="Navigation">
    |  |  |
    | --- | --- |
    | `h j k l` | Move `← ↓ ↑ →`. |
    | `w / b` | Jump to next/previous word. |
    | `0 / $` | Go to start/end of line. |
    | `gg / G` | Go to top/bottom of file. |
    | `^ + h/j/k/l` | Move between panes. |
    | `⌥ + ←/→` | Jump by word in terminal input. |
    | `⌘ + ←/→` | Jump to start/end of line in terminal input. |
  </SheetCard>
  <SheetCard title="Explorer and Search">
    |  |  |
    | --- | --- |
    | `<leader>e` | Toggle Neo-tree. |
    | `<leader>ff` | Find files. |
    | `<leader>fg` | Search text in project. |
    | `<leader>fb` | Open buffers list. |
    | `<leader>fr` | Open recent files. |
  </SheetCard>
  <SheetCard title="Code Actions">
    |  |  |
    | --- | --- |
    | `gd` | Go to definition. |
    | `gr` | Find references. |
    | `K` | Show hover docs. |
    | `<leader>ca` | Open code actions. |
    | `<leader>rn` | Rename symbol. |
  </SheetCard>
  <SheetCard title="macOS Terminal">
    |  |  |
    | --- | --- |
    | `⌘ + c` | Copy selected terminal text. |
    | `⌘ + v` | Paste into terminal. |
    | `⌘ + k` | Clear terminal viewport (Ghostty). |
    | `⌥ + click` | Move cursor quickly in shell line editor. |
  </SheetCard>
</SheetGrid>

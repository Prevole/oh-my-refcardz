<SheetGrid>
  <SheetCard title="Containers">
    |  |  |
    | --- | --- |
    | `docker ps` | List running containers. |
    | `docker ps -a` | List all containers. |
    | `docker logs -f <id>` | Follow logs. |
    | `docker exec -it <id> sh` | Open shell in container. |
  </SheetCard>
  <SheetCard title="Images">
    |  |  |
    | --- | --- |
    | `docker build -t app .` | Build from Dockerfile. |
    | `docker images` | List local images. |
    | `docker rmi <image>` | Remove image. |
    | `docker image prune` | Clean dangling images. |
  </SheetCard>
  <SheetCard title="Compose">
    |  |  |
    | --- | --- |
    | `docker compose up -d` | Start services in background. |
    | `docker compose down` | Stop and remove services. |
    | `docker compose logs -f` | Follow service logs. |
    | `docker compose exec <service> sh` | Shell into a service. |
  </SheetCard>
</SheetGrid>
